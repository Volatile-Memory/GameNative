### 1.3 7 Domain Preference Repositories Implementation
All 7 domain preference repositories in `app/src/main/java/app/gamenative/preferences/` are fully implemented:
1. `AuthPreferences.kt` / `DefaultAuthPreferences.kt`:
   - Handles Steam/Epic credentials, persona state (`EPersonaState`), AES token encryption (`Crypto.encrypt`/`decrypt`), session clearing (`clearSteamSession`), and reactive Flows (`personaStateFlow`, `steamUserSteamId64Flow`, `usernameFlow`, `steamOfflineModeFlow`, `epicOfflineModeFlow`).
2. `ContainerPreferences.kt` / `DefaultContainerPreferences.kt`:
   - 1:1 mapping for Wine, Proton, FEX, Box86/64, drivers, suspend policy (`Container.normalizeSuspendPolicy`), and container parameters.
3. `InputPreferences.kt` / `DefaultInputPreferences.kt`:
   - Handles Steam Input, XInput, DInput, button swapping, hint overlays, and opacity.
4. `HudPreferences.kt` / `DefaultHudPreferences.kt`:
   - Handles performance metrics toggles, graphing configs, HUD layout positioning, `PerformanceHudConfig` conversion helpers, and `hudConfigFlow`.
5. `LibraryPreferences.kt` / `DefaultLibraryPreferences.kt`:
   - Handles pane layouts, filter flags, sort options, recommendations cache, custom game paths, favorites persistence with monotonic concurrency locking (`favoritePersistenceLock`), and GOG/Amazon path migration state.
6. `DownloadPreferences.kt` / `DefaultDownloadPreferences.kt`:
   - Handles Wi-Fi download restrictions, speed caps, external storage paths, and per-source sync directories (`getFrontendSyncDir`/`setFrontendSyncDir`).
7. `GeneralPreferences.kt` / `DefaultGeneralPreferences.kt`:
   - Handles theme, palette style (`com.materialkolor.PaletteStyle`), language, orientation masks (`Orientation.toInt`), telemetry flags, crash tracking, and component manifests.
